# MoraWorld

Project website at [yfcharm.github.io/MoraWorld](https://yfcharm.github.io/MoraWorld/).

The site is static. GitHub Pages publishes the repository root on `main`. The viewpoint memory comparison uses the original paired recordings.

For a local preview, run `python3 -m http.server 8000` in your checkout and open `http://localhost:8000/`. To propose an edit, create your own branch, commit the change, and open a pull request to `main`.
