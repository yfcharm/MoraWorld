Why a world simulator

Robots learn by doing. A world simulator gives a policy somewhere to do it, as many times as it needs.

1 · Code2 · Tabletop grey box3 · Scene grey box4 · Virtual camera + body5 · First person, rendered6 · World model

[placeholder] storyboard for the overview GIF. The real one replaces this loop.

MoraWorld starts from code. You write the scene as a grey box: first a table, then the room around it, then a robot body with a camera on its head. The model takes what that camera sees and renders it as realistic first-person video. The code keeps the world exact and repeatable, and the rendering makes it look like the real one.

WORLD MODEL = CODE + RENDER

With both halves, a policy gets what real hardware can't give it cheaply:

  • DataAs many episodes as it needs, in rooms that don't exist yet.
  • EvaluationThe same test, repeated exactly, for every checkpoint.
  • Self-improvementPractice, fail and retry without wearing out a robot.

OVERVIEW

1 / 2 · WHAT GOES IN

A policy, and as much of the world as you have.

The policy sends actions for the base, the arms and the head camera. The camera isn't a separate thing: it is the same mobile manipulator, with a position and a direction to look in. The world around the robot can be empty, sketched with a few rough proxies, or built out as a full simulator. MoraWorld renders all three.

CODE

Build the world in code

A grey box is more than shapes. It carries the physics too, and you set it in a few lines.

build_scene.py[illustrative API, replace with the real one]
import moraworld as mw

# world
scene = mw.Scene(gravity=(0, 0, -9.81), dt=1/240, substeps=4)

# objects, with the physics that matters for contact
table = scene.add(mw.Box(size=(1.2, 0.6, 0.04)), static=True,
                  friction=0.6)
mug = scene.add(mw.Cylinder(r=0.04, h=0.10), on=table,
                mass=0.25, friction=0.8, restitution=0.1)
drawer = scene.add(mw.Drawer(travel=0.35, damping=2.0), under=table)

# robot and its head camera
robot = scene.add(mw.Robot("mobile_dual_arm.urdf"),
                  control_hz=30, kp=400, kd=40, grip_force=40)
cam = robot.mount(mw.Camera(fov=90, res=(1280, 720), fps=30),
                  link="head")

# many versions of the same room
scene.randomize(friction=(0.4, 1.0), mass=0.2, lighting=True, seed=7)

# code + render
world = mw.MoraWorld(scene, camera=cam)
frame = world.step(action)   # physics first, then pixels
